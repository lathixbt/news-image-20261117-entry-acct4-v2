A one-page newspaper front page summing up Tuesday 17 November 2026:
2 hero stories, 10 illustrated panels and 18 further briefs — 30
verified stories across 6 continents in total, with a world map
showing where each story happened.

`draw.py` draws the whole page with PIL only (no network, no
randomness, fully deterministic) and writes `entry.png` (1024x1024).
`main.py` is a standard-library-only entrypoint: it copies the
pre-rendered `entry.png` into `MAKEFUN_OUTPUT_DIR`. Run the
entrypoint with:

```
MAKEFUN_OUTPUT_DIR=. python3 main.py
```
